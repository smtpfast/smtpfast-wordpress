# Security policy

## Supported versions

Only the latest release of the SMTPfast plugin gets security fixes.

## Report a vulnerability

Email security@devops-daily.com with the steps to reproduce, the plugin and WordPress versions, and the impact. Do not open a public issue.

We acknowledge reports within 48 hours and tell you when a fix is released. You can also report through the [Wordfence](https://www.wordfence.com/threat-intel/) or [Patchstack](https://patchstack.com/database/) programs for WordPress plugins.
